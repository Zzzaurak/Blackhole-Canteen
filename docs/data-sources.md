## 供餐时间

[国际学生学者校园生活手册](https://is.tsinghua.edu.cn/guojixueshengxuezhexiaoyuanshenghuoshoucezhongwenban.pdf)公开索引中的学生食堂表给出：早餐 06:30—09:00，午餐 11:00—13:00，晚餐 17:00—19:00；桃李一层另有 19:00—23:00 夜宵。

依用户要求，本次将这三餐时段作为九个主食堂的统一作业默认值；桃李合并为 17:00—23:00，玉树按用户 2026-10-05 修订为 17:00—22:00。没有声称每个食堂的每层在这些时段均开放。对于荷园、澜园、芝兰等也使用默认值，未逐个核实其当前真实供餐时段。

页面统一显示“参考供餐时段”，不用“实时营业”。假期、临时调整和窗口差异不在本初稿的自动处理范围内。

## 主观数据与伴星

- 听涛、芝兰的价格为 `null`，不填充猜测价格。
- “好吃程度”的数值仅为将用户语言转换成算法初始值：一般 3、稍好吃 3.7、还不错 4、很好吃 4.8、明显不合口味 1.5（满分 5）。后续用户评分会逐渐调整。
- 清清快餐按用户昵称展示，在详情标注官方名称“清青快餐”，与清芬共用地理位置但不独立推荐。
- 麦当劳、必胜客来自用户提供的澜园周边描述，门店位置、其他商户、营业时间未核实，作为装饰伴星和文字介绍，不当成可导航或可推荐的已核实门店。
