# 初稿设计 · 今天吞哪颗星？

## 一顿饭，一次相遇

“我”是一只在棒旋星系中漂泊的小黑洞，暂名小吞。抽取决定靠近哪类恒星；实际吃完并记录才吞掉那颗星。食堂位置只影响概率，不决定天体构图。同类恒星可反复出现，因此食堂不会因一次吞食永久消失。

视觉采用深靛蓝、柔和紫色星尘、奶油色光线和浅绿色操作按钮。可爱 IP 承担情绪表达，页面保留足够的暗色留白。2026-10-05 按手绘参考改为星系内部局部俯视：小吞固定在中部，星海多层缓慢后退，有供餐候选时进入铺满视野的旋臂云气和密集星场，无候选时进入更稀疏的臂间。名称在悬停、聚焦或选中时显示。主操作只需时间、位置、心情和可选偏好；没有账号、路线规划、实时菜单或排队预测。

## 九个食堂的选星

| 食堂 | 恒星设定                  | 选择依据                                                          |
| ---- | ------------------------- | ----------------------------------------------------------------- |
| 紫荆 | G 型主序星（G2 V 类太阳） | 便宜、丰富、味道普通，作为日常能量的基准                          |
| 桃李 | M 型红矮星                | 低质量红矮星长寿，借喻晚餐/夜宵一直持续到 23:00；暖红色呼应重口味 |
| 清芬 | 脉动变星 + 一颗快餐伴星   | 亮度节律借喻工作日人潮；不把真实拥挤当作实时数据                  |
| 听涛 | 白矮星                    | 小而致密对应体量小；不好吃来自个人印象，不是白矮星的物理性质      |
| 观畴 | K 型橙矮星                | 比太阳色泽更温暖，作为图书馆和物理楼附近的稳定选择                |
| 荷园 | F 型黄白主序星            | 用明亮、干净的黄白色表现值得专门走去的好味道                      |
| 澜园 | 多星系统                  | 澜园为主星，周边麦当劳、必胜客等用伴星呈现                        |
| 玉树 | 红巨星                    | 大体量、暖色和明显辉光对应份量大、好吃且昂贵的犒劳餐              |
| 芝兰 | A 型蓝白主序星            | 用蓝白光与其他食堂区分，保留价格未知，不虚构更多特性              |

分类故意混合了光谱型、演化阶段、变光行为与多星结构，用作创意类比。光谱颜色尽量有依据，不将 F 型画成蓝色、A 型画成紫色，也不称白矮星为主序星。

参考：[NASA 恒星类型](https://science.nasa.gov/universe/stars/types/)、[NASA：红矮星与寿命](https://science.nasa.gov/exoplanets/stars/)、[NASA：K 型星](https://science.nasa.gov/missions/hubble/goldilocks-stars-are-best-places-to-look-for-life/)。

## 两页与交互

首页：主视觉星系 + 右侧引力设置。点恒星可看食堂详情；抽取时先保存概率快照，再演出选中恒星的靠近与高亮。结果可选定、重抽、记录或展开概率条形图。关闭结果不会删除推荐。

日志页：用餐统计、已选定待记录的目的地、真实用餐卡片、按食堂筛选、最近推荐历史。推荐食堂与实际食堂分别显示。任何记录支持编辑和删除；一次推荐最多关联一顿实际用餐。

食堂图鉴、设置、备份和记录表单采用原生 dialog，不增加页面。键盘可操作、Escape 可关闭、弹窗保持焦点；支持系统减少动态效果及手动暂停。

## 推荐计算

1. 按输入时刻过滤食堂，区间为左闭右开，13:00、19:00、23:00 等结束时刻不继续推荐对应已结束时段。当前记录均有作业默认时段；伴星没有独立时段，因此不单独参与。
2. 候选校园参考点与出发点计算平面欧氏距离。距离分数为 `1 - 当前距离 / 候选最大距离`。这只表示相对远近，不声称是步行距离。
3. 初始权重：距离 0.35、偏好 0.25、口味/历史评分 0.25、新鲜感 0.15。未选偏好时该项权重为 0，重新归一化。
4. 偏好分是匹配标签数 / 所选标签数；口味分使用 `(个人印象分 × 2 + 历史评分总和) / (2 + 评分数) / 5`；新鲜感为 `1 - 最近三次实际用餐中该食堂次数 / 3`。
5. 不想走远时距离权重翻倍；想探索时新鲜感权重翻倍；想吃熟悉的时口味/历史权重翻倍。没有记录时仍可用个人印象分启动。
6. 最终概率为 `0.8 × 归一化评分 + 0.2 / 候选数`，使用一次随机数落入累计概率区间。算法是简单的可解释启发式。

重抽不会改变实际用餐历史。概率快照不随之后评价回写；“为什么遇见它”展示当时的结果。

## 数据边界

纯前端 localStorage + JSON 备份，视频和图片是静态文件，不进入 localStorage。不能自动跨设备同步。损坏备份、版本不兼容、未知食堂、评分越界、悬空关联、重复用餐关联和不正确的概率总和均拒绝导入。

此版本没有后端接口，也无需任何模型配置。旧的全景视频背景开关停用，未来的俯视转斜平视与反向返回视频将作为独立转场层接入。

## 旋臂内部的质感修订（2026-10-05）

参考用户提供的星系照片，提取蓝白年轻星团、细密恒星、弯曲分叉的暗尘和弥散云气。镜头仍然跟随小吞，处在旋臂的一小块区域，银河中心和完整旋臂轮廓不在当前画幅中。饭点时云气横跨整个视野，内部的暗纹是遮光尘埃，而不是旋臂外沿。

`src/galaxyTexture.ts` 用周期噪声、坐标扰动和分层颗粒生成可无缝平铺的纹理；数万颗细小恒星按云气与尘埃密度分布，并叠加蓝白星团。纹理只生成、缓存一次，逐帧只移动与合成；前景恒星以不同速度缓慢漂移。低频结构负责云气大形状，中高频结构打散边缘，避免一条整齐的发光线。

`src/Galaxy.tsx` 在供餐状态切换时让宽渐变边界扫过画面。完全进入旋臂后边界移出视野，完全离开后只保留稀疏前景恒星与很淡的远景。暂停与减少动态效果模式直接显示对应静止状态。保持原有推荐、恒星详情和日志交互；本轮没有调用图像或视频模型。
