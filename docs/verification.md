- `npm run build`：通过，含 TypeScript 检查与生产打包。
- `npm test`：24 项测试通过。覆盖默认三餐起止边界、桃李夜宵、无候选、概率归一化、抽样区间、距离和偏好影响、历史评价、地理与星图坐标分离、备份恢复和无效关联等。

## 尚未验证的部分

未生成或接入正式背景视频，因此尚未验证该视频的首尾一致、编码兼容性和实际手机播放。Canvas 动画回退与视频接入代码已经准备；不能把这一项当成老师的“动态视频背景”要求已经完成。

营业时间按用户指定默认值与公开早餐参考录入，没有逐个核验所有楼层、窗口。校园参考点来自地图人工定位，宿舍使用区域代表点，未做道路导航精度测试。
