# 今天吞哪颗星？ · Stellar Bites

一只小黑洞的清华觅食日常。React + TypeScript 纯前端作业初稿，包含「星际觅食」和「吞星日志」两个页面。

## 运行

需要 Node.js 22.12+（本机验证为 Node.js 24），在本目录运行：

```sh
npm ci
npm run dev
```

打开终端显示的本地网址，默认 http://127.0.0.1:5173。不要直接双击 `index.html`；本地存储区分网站的协议、主机与端口。

```sh
npm run build       # TypeScript 检查和生产构建
npm run preview     # 预览 dist（另一个端口拥有独立的本地记录）
npm test            # 时段、概率、历史评价和备份校验
npm run test:e2e    # 实际浏览器测试，需要已安装 Google Chrome
```

构建后的 `dist/` 可放到普通静态托管服务，不需要后端。所有图片保存在本项目，字体使用系统字体；运行不依赖外部字体或地图 API。

## 初稿完成情况

- 九个食堂与恒星设定：紫荆、桃李、清芬、听涛、观畴、荷园、澜园、玉树、芝兰。
- 一至六教、紫荆学生公寓、南区本科生公寓、李文正图书馆、新物理楼及食堂参考位置。
- 独立于校园地理的动态棒旋星系、可点选恒星、小黑洞漂移和饭后吞星反馈。
- IP 原图（透明背景）与修改背景后的星系关键帧，均由内置 imagegen 生成并保存。
- 按供餐时间、距离、个人印象、心情、偏好、最近用餐和评分进行加权抽取。
- 推荐与实际用餐分别保存，支持重抽、选定目的地、补记、编辑、删除、筛选及推荐历史。
- localStorage 持久化、JSON 导入导出、无候选状态、保存失败提示、减少动态效果和移动端布局。
- 视频接入位置、5 秒循环视频分镜与提示词已准备。

**本次未调用任何视频生成模型，也未读取课程 API 凭据。当前首页的 Canvas 动画不是老师要求的“视频背景”，最终提交前仍需接入真实视频。**

## 接入未来的视频

1. 将生成好的、首尾衔接的无声 MP4 保存为 `public/assets/galaxy-loop.mp4`。
2. 复制 `.env.example` 为 `.env.local`，保留 `VITE_GALAXY_VIDEO=./assets/galaxy-loop.mp4`。
3. 重启开发服务；生产部署时重新 `npm run build`。

首页已有 `<video muted loop playsInline>`、静态封面、暂停入口和加载失败时的 Canvas 回退。交互恒星和可移动 IP 仍由前端叠加。背景视频最好只保留星系环境，避免与可移动角色重复；现有带角色关键帧用于视觉参考和 IP 流程展示，最终背景视频可在即梦中去掉前景角色，或重新准备无角色场景图。

详见 [素材与视频制作说明](docs/media-prompts.md)。即梦是原作业流程中的指定工具；课程 TokenHub 的混元/Kling 属于后续可选资源，不能默认等价于已完成即梦步骤。

## 使用和数据说明

- 默认按当前设备时间，早餐 06:30—09:00、午餐 11:00—13:00、晚餐 17:00—19:00；桃李延长到 23:00。关闭时刻不再进入候选。
- 非饭点可手动改成 07:30、12:00、18:00；21:00 可稳定演示只抽到桃李。时段是作业参考值，不是实时营业查询。
- 口味与价格来自使用者主观评价，听涛和芝兰未知价格保留为空。
- 清清快餐（官方写作“清青快餐”）、麦当劳、必胜客作为伴星展示，暂不独立抽取。未编造门店具体营业时间。
- 原始数据保存在 `stellar-bites:v1`。清空浏览器网站数据会丢失记录；请定期导出。导入前会预览记录数量并提示替换。
- 读取损坏数据时暂停覆盖，可先导出原始内容再恢复有效备份；写入失败时不把操作显示为已成功。
- 星图位置纯属构图；校园坐标仅用于远近评分，不显示伪精确的步行米数和时间。
